# MWIindex · 银河生产利润指数

仓库地址：[dakokili/MWIindex](https://github.com/dakokili/MWIindex)。

在《银河奶牛放置》游戏页面右下角添加「◈ 利润指数」按钮，点击展开/收起面板。提供 **三采、三制造、饮食**三个综合指数，以及挤奶、采集、伐木、锻造、缝纫、制作、烹饪、冲泡八个细分指数，支持日线、周线、月线。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)；按扩展提示启用用户脚本权限。
2. 将本仓库根目录的 **[mwi-profit-indices.user.js](./mwi-profit-indices.user.js)** 全部内容粘贴到 Tampermonkey 新建脚本，保存。

## 使用

- 默认同时显示三个综合指数。上方技能按钮查看细分指数；点击 K 线查看开高低收、样本数、成分、额外收入和最佳饮食。
- 数字的单位是 **金币 / 日**；卡片大字是所选周期的日均利润。红涨绿跌，单样本日显示平线并提示无法观测日内波动。
- 可以切换日/周/月，调整最低等级、已观测成交量、价差、报价覆盖率和税率。
- 「刷新行情」重新抓取；「导出 JSON」保存所有指数、成分和规则信息。

## 计算口径

**产物与额外掉落按买一，原料和饮食按卖一；扣 4% 卖出税。** 默认配装来自 [Milkonomy](https://www.milkonomy.top/) 对应的 [开源项目](https://github.com/Polokikiki/Milkonomy)，固定版本以保证历史可复算。100 级角色、80 级工具 +10、所有生活房屋 4 级，以及网站默认的特殊装备 +10。

每个技能排除行动等级低于 20 的产品、装备、护符、非交易商品及混合采集区；通过流动性筛选后取综合评分前五（不足五种按实际数量），等权计算日均利润。综合指数对所属技能等权。综合评分为 **日均净利润排名 50% + 已观测成交量排名 25% + 双边报价质量排名 25%**。

精华、随机稀有产物、不可交易箱子的开箱期望、牛铃折算均包含在收益中。

完整公式、缺失报价策略、箱子税务处理、选品与 K 线定义见 **[计算与数据口径](docs/methodology.md)**。

## 数据范围与边界

默认历史源为 [Iceking233/mwi-market-data](https://github.com/Iceking233/mwi-market-data)：官方行情归档包含买卖报价、成交均价和成交量。核验时（2026-10-13）最近 60 天包含 556 个日内时点；并不是每个小时都成功归档。**成交量仅统计观测到的小时，不乘 24、不跨缺口补齐。** 默认要求每天已观测成交量至少 1,000 件，同时报价覆盖率 ≥80%、相对价差 ≤20%。

上游将 60 天前的报价压缩成每日中位数，无法恢复日内高低价，因此脚本不会将这些记录用于 K 线。浏览器会逐步积累最多 400 天的原始样本；首次安装选择 180/400 天不会凭空得到那么长的历史。缺口不插值，图中 `⋮` 表示日历周期缺口，过期/失败提示会显示在面板中。

历史全部使用同一版配装和配方回算，不能代表当时版本的真实角色收益。每天按当日已获得样本选品，当前日成分和 K 线会随新数据变化；这是描述性利润指标，不是无前视偏差的可投资回测。样本不完整时，日均和高低点也只代表已观测行情。

已调查的 MWIApi、Milkonomy 自身归档及其它接口见 [数据源核验](docs/sources.md)。

## 开发与验证

```bash
npm ci
npm test
npm run build
npm run test:browser
```

- Node.js 22+。浏览器测试默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定安装位置。
- `npm run check` 运行单元测试、构建和 Chromium 集成测试。
- `tests/fixtures/official-snapshots.json` 是真实公开行情的小样本；常规测试不依赖在线 API，不将模拟行情写入正式脚本。
- 浏览器测试在模拟游戏壳与 GM 接口中验证完整打包脚本，覆盖展开/收起、周期、成分、键盘、窄屏、JSON 导出、离线缓存与首次网络失败。没有自动登录真实游戏账户。
- 更新固定规则快照：检出并审核 Milkonomy 源码，运行 `node scripts/import-milkonomy.mjs /path/to/Milkonomy`，人工核对默认配装与公式是否改变，再测试与构建。该工具仅导入数据，不会自动移植未来版本算法。

```
src/model.js       默认配置、饮食组合、每小时产出/成本系数
src/indices.js     每日选品、综合指数、日周月 OHLC
src/data.js        官方分片适配与时间对齐
src/transport.js   只读请求、有限并发、重试、IndexedDB 缓存
src/chart.js       SVG K 线（无第三方运行库）
src/main.js        油猴面板与交互
```
