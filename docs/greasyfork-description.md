# MWI 银河生产利润指数

在《银河奶牛放置》游戏页面右下角添加“利润指数”按钮，展开即可查看生产收益的日线、周线和月线 K 线。

- 三个综合指数：三采、三制造、饮食。
- 八个行业：挤奶、采集、伐木、锻造、缝纫、制作、烹饪、冲泡。
- 金额统一为 **M/日**（百万金币），收盘报价红涨绿跌，下方显示涨跌额与百分比。
- 点击单根 K 线或选取区间查看涨跌；单根与前收比较，区间用末收与首根前收比较。
- 支持默认配装＋最佳饮食，或当前玩家等级、装备、房屋等增益＋所选饮食。
- “刷新行情”更新价格；“更新装备数据”重新读取当前角色配置。
- 各分页成分详情同步展开/收起，并支持导出 JSON。

## 计算规则

产物按买一，材料和饮食按卖一（有金币商店价时取更低值），扣 4% 卖出税，并计入精华、稀有掉落和开箱的期望收入。

最低行动等级为 20，且不高于当前配置的技能基础等级。日内已观测成交量至少 10,000 件；每个行业最多选 3 种。除冲泡外按日均利润排序，冲泡按利润排名、成交量排名各 50% 选品。综合指数再从所属行业的入选品种中按利润选前 5，品种等权；不足时使用实际数量。

## 使用

安装后刷新游戏页面，点击右下角“利润指数”。首次读取历史行情需要一些时间，之后会复用浏览器本地缓存。换装、换饮食或升级后，在玩家模式点击“更新装备数据”。

通过本页安装后，可由脚本管理器自动检查版本更新，请保持自动更新开启。

## 数据说明

行情来自公开普通服市场归档：[mwi-market-data](https://github.com/Iceking233/mwi-market-data)。计算模型基于 [Milkonomy](https://www.milkonomy.top/) 的开源公式和固定规则快照。

玩家模式只读游戏页面的生产配置，不代替玩家交易、不上传角色数据。配置仅在内存中使用；手动导出的 JSON 含角色名及生产配置。

成交量仅统计实际抓取到的时段；历史有缺口，不插值补价。更早的每日中位数不能还原 K 线，首次使用不会获得完整 400 天历史。历史按当前所选配置统一回算，显示的是估算收益，不是账户实际收入。
