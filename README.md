# MWIindex · 银河生产利润指数

仓库地址：[dakokili/MWIindex](https://github.com/dakokili/MWIindex)。

在《银河奶牛放置》游戏页面右下角添加「◈ 利润指数」按钮，点击展开/收起面板。提供 **三采、三制造、饮食**三个综合指数，以及挤奶、采集、伐木、锻造、缝纫、制作、烹饪、冲泡八个细分指数，支持日线、周线、月线。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)；按扩展提示启用用户脚本权限。
2. 打开 **[Greasy Fork 安装页](https://greasyfork.org/zh-CN/scripts/600168)**，点击「安装此脚本」，在 Tampermonkey 弹窗中确认安装。
3. 刷新游戏页面，点击右下角「利润指数」。保持脚本管理器的自动更新开启，以接收后续版本。

原来从 GitHub 或粘贴代码安装的用户，可通过 Greasy Fork 页面重新安装一次以切换更新来源，确认没有同时启用两份脚本。维护者的同步配置与更新流程见 **[Greasy Fork 发布与自动更新](docs/greasyfork-publishing.md)**。

### v1.3.1 修复

- 修复旧版 React 挂载结构下，即使已登录仍提示「尚未读到完整角色数据」的问题；支持旧根容器、旧组件标记及当前挂载树。
- 读取时优先使用当前挂载组件，不让旧组件引用或不完整候选遮挡完整角色数据。确实缺少字段时提示具体数据类别。
- 更新脚本后刷新游戏页面，再切换到「当前玩家」模式。已处于玩家模式时可点击「更新装备数据」。

## 使用

- 各分页的成分细节统一展开或收起；在任一卡片切换后，综合页与技能页保持一致，切换周期、时间范围或更新数据也会保留状态。
- 默认同时显示三个综合指数。上方技能按钮查看细分指数；点击 K 线查看开高低收、样本数、成分、额外收入和最佳饮食。
- 数字的单位是 **M / 日（百万金币，1M = 1,000,000 金币）**；卡片大字为所选周期末的收盘利润指数，日均利润保留在详情。报价及下方涨跌额、涨跌幅采用红涨绿跌，持平或无前收显示灰色。单样本日显示平线并提示无法观测日内波动。
- 单击 K 线查看该日期/周期的涨跌；Shift＋单击可扩展选择范围，也可点「选取区间」后依次选起点、终点（支持反向选择），或点「全部范围」。单根比较本根收盘与前收，区间比较末根收盘与首根前收，百分比不逐日累加。
- 缺少前收时显示「无前收」；前收为零时不计算百分比；前收为负时以其绝对值为分母，亏损收窄记为上涨。历史有缺口时使用前一可用周期的收盘，比较基准可悬停涨跌文字查看。
- 可以切换日/周/月；最低行动等级固定为 20，每日已观测成交量下限固定为 10,000，不设价差和覆盖率筛选，不提供参数修改入口。
- 「切换模式」在默认配装＋最佳饮食与当前玩家配装＋所选饮食之间切换，重算整段历史。玩家模式读取游戏当前角色的技能等级、装备强化与房屋增益、社区/成就/个人等增益和各技能饮食槽；不会自动替换玩家饮食。换装、升级或更换角色后点击「更新装备数据」重新读取。玩家模式会在选品前排除所需等级高于对应技能基础等级的配方。
- 玩家模式假定所选饮食持续补充并计入成本；战斗专用食物不参与生活技能计算。角色数据未就绪或结构不兼容时明确报错，保留上一模式的结果。
- 「刷新行情」更新行情，保留当前计算配置；独立的「更新装备数据」按钮在玩家模式下可用，重新读取角色配置并使用已有行情缓存重算（缺少的数据会补充加载）；「导出 JSON」保存所有指数、成分和规则信息。

## 计算口径

**产物与额外掉落按买一，原料和饮食按卖一；扣 4% 卖出税。** 默认配装来自 [Milkonomy](https://www.milkonomy.top/) 对应的 [开源项目](https://github.com/Polokikiki/Milkonomy)，固定版本以保证历史可复算。100 级角色、80 级工具 +10、所有生活房屋 4 级，以及网站默认的特殊装备 +10。

每个行业排除行动等级低于 20 的产品、装备、护符、非交易商品及混合采集区，并要求当日已观测成交量至少 **10,000 件**。除冲泡外，按日均净利润从高到低选 **前 3 种**，成交量只作门槛；冲泡仍按 **利润排名 50% + 成交量排名 50%** 选前三。

综合指数从所属 n 个行业已经选出的最多 3×n 个品种中，按日均净利润统一排序取 **前 5 种**，对这些品种等权计算，不再平均行业指数。少于 3/5 种时按实际数量计算；没有合格成分则不输出指数。综合页及导出仅列出实际入选的成分。

精华、随机稀有产物、不可交易箱子的开箱期望、牛铃折算均包含在收益中。

完整公式、缺失报价策略、箱子税务处理、选品与 K 线定义见 **[计算与数据口径](docs/methodology.md)**。

## 数据范围与边界

默认历史源为 [Iceking233/mwi-market-data](https://github.com/Iceking233/mwi-market-data)：官方行情归档包含买卖报价、成交均价和成交量。核验时（2026-10-13）最近 60 天包含 556 个日内时点；并不是每个小时都成功归档。**成交量仅统计观测到的小时，不乘 24、不跨缺口补齐。** 固定要求每天已观测成交量至少 10,000 件。不筛选价差或报价覆盖率；计算某个时点利润必需的买一/卖一报价仍须有效，缺失时点不填零。

上游将 60 天前的报价压缩成每日中位数，无法恢复日内高低价，因此脚本不会将这些记录用于 K 线。浏览器会逐步积累最多 400 天的原始样本；首次安装选择 180/400 天不会凭空得到那么长的历史。缺口不插值，图中 `⋮` 表示日历周期缺口，过期/失败提示会显示在面板中。

历史全部使用所选模式的一套配置和同一版配方回算，不能代表当时版本的真实角色收益。每天按当日已获得样本选品，当前日成分和 K 线会随新数据变化；这是描述性利润指标，不是无前视偏差的可投资回测。样本不完整时，日均和高低点也只代表已观测行情。

已调查的 MWIApi、Milkonomy 自身归档及其它接口见 [数据源核验](docs/sources.md)。

## 开发与验证

```bash
npm ci
npm test
npm run build
npm run test:browser
```

- Node.js 22+。浏览器测试优先使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定安装位置；也可运行 `npx playwright-core install --with-deps chromium` 使用 Playwright 浏览器。
- `npm run check` 运行单元测试、构建和 Chromium 集成测试。
- `tests/fixtures/official-snapshots.json` 是真实公开行情的小样本；常规测试不依赖在线 API，不将模拟行情写入正式脚本。
- 浏览器测试在模拟游戏壳与 GM 接口中验证完整打包脚本，覆盖展开/收起、周期、成分、键盘、窄屏、JSON 导出、离线缓存与首次网络失败。玩家模式使用真实 React 16 挂载的测试组件，覆盖旧根容器、DOM 标记回退及重新渲染后的角色读取；新版根结构另有单元测试。React 仅为开发测试依赖，不打包进用户脚本。没有自动登录真实游戏账户，游戏更新改变状态字段时可能需要适配。
- 更新固定规则快照：检出并审核 Milkonomy 源码，运行 `node scripts/import-milkonomy.mjs /path/to/Milkonomy`，人工核对默认配装与公式是否改变，再测试与构建。该工具仅导入数据，不会自动移植未来版本算法。

```
src/model.js       默认配置、饮食组合、每小时产出/成本系数
src/indices.js     每日选品、综合指数、日周月 OHLC
src/data.js        官方分片适配与时间对齐
src/transport.js   只读请求、有限并发、重试、IndexedDB 缓存
src/chart.js       SVG K 线（无第三方运行库）
src/main.js        油猴面板与交互
src/player.js      只读当前角色状态与生产增益
```
